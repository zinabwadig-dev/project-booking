# Project 2 · Interactive booking website (starter)

Turn a landing page into a booking site: the visitor picks services, sees the total, fills a form and sends the booking on WhatsApp.

## How to start

1. Open the folder in VS Code.
2. Open `index.html` with Live Server.
3. Open `script.js` and do the steps in order, from STEP 1 to STEP 10.
4. After each step, refresh the page and check the Console (F12).

The HTML and CSS are ready. You may change the texts, colours and services to match your own business, but do not rename the ids: the JavaScript steps use them.

## Rules

- Vanilla JavaScript only, no libraries.
- Write your own code and be ready to explain it.

## Checklist

- [ ] Services stored as an array of objects (name, price)
- [ ] Service cards are created from the array with JavaScript
- [ ] Clicking a service selects or unselects it
- [ ] The total updates live
- [ ] Form has name, email, phone and quantity
- [ ] Validation blocks wrong input
- [ ] Error messages appear next to the right field
- [ ] Success message when everything is valid
- [ ] Unfinished booking is saved in localStorage and restored on reload
- [ ] Booking summary sent as a WhatsApp link
- [ ] No errors in the Console
- [ ] Works with mouse, keyboard and on a phone
- [ ] Deployed online
